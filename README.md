# 🎮 Jogo da Velha (Tic-Tac-Toe) — React + Vite

> Projeto desenvolvido para o curso Técnico em Desenvolvimento de Sistemas.

---

## 📌 Sobre o Projeto

Este projeto é uma versão customizada e refatorada do clássico **Jogo da Velha**, originalmente baseado na documentação oficial do React. 

O objetivo principal é aplicar e consolidar os conceitos de desenvolvimento Front-end estudados no curso, transformando a aplicação simples do tutorial em um projeto de nível profissional com arquitetura modular, estilos escopados e boas práticas de programação.

### 🎯 Objetivos do Projeto
- **Componentização Modular:** Separação das responsabilidades da interface em componentes independentes.
- **Gerenciamento de Estado:** Manipulação do estado com `useState` e controle de imutabilidade.
- **Design System Encapsulado:** Uso de **CSS Modules** combinados com a metodologia **BEM (Block, Element, Modifier)** e Variáveis CSS.
- **Clean Code e Acessibilidade:** Organização do código, reutilização, nomenclaturas padronizadas e uso de HTML semântico.

---

## 🛠️ Linguagens e Tecnologias Utilizadas

### Linguagens
- **HTML5:** Estruturação semântica da aplicação.
- **CSS3:** Estilização responsiva e customizada.
- **JavaScript (ES6+):** Lógica do jogo, manipulação do estado e eventos.

### Ferramentas e Frameworks
- **React:** Biblioteca para construção da interface de usuário baseada em componentes.
- **Vite:** Ferramenta de build rápida para o ambiente de desenvolvimento.
- **CSS Modules:** Encapsulamento de estilos por componente para evitar conflitos de classes.
- **Bootstrap:** Auxílio na estrutura e elementos responsivos da página (quando aplicável).
